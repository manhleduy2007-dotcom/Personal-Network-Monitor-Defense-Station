# Personal-Network-Monitor-Defense-Station
This is my first project about cyber security: 
Một số kiến thức cần nắm được: 
* Mạng Lan: chỉ 1 nơi cụ thể => project tập trung vào mạng LAN ở trong nhà
* IP Address (Internet Protocol Address) => địa chỉ định danh mỗi thiết bị trong mạng (Không thể trùng IP trong mạng LAN): 
- IPV4 => địa chỉ gồm 4 số cách nhau => chuẩn theo CIDR notation => để hệ thống mạng biết ranh giới giữa địa chỉ "khu vực mạng" và phần địa chỉ "từng thiết bị" 
- Sử dụng thư viện nmap (phần mềm quét mạng/ bảo mật dưới dạng dòng lệnh)
- I use venv to support the library for different versions of Python 
- Beside, I use Scapy specialized for communicate with network packets 
- Port: cổng mạng và sử dụng Port Scan để quét xem các thiết bị nào đang online
